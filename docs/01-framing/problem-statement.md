# 问题定义与形式化

本文把"决策空间爆炸"从一句直觉变成可测量、可证伪的命题。**若本文的度量任务显示空间并不爆炸，课题动机必须重写。**

## 1 程序模型

一个 MegaKernel 实现方案是一个**决策向量** $d=(F,T,B,R,S)$，五元组的定义见 `N-PROPOSAL §1.2`。为便于分析，把 $d$ 视为分层变量：

$$d = (v_1,\; v_2,\; v_3), \quad v_k \in \mathcal{D}_k,\ k\in\{\text{Tile},\text{Buffer},\text{Register}\}$$

其中：

- $v_1 = (F, A)$：融合划分 + 每组算法方案；
- $v_2 = (B_{\text{size}}, B_{\text{reuse}}, \text{expand-scope})$；
- $v_3 = (\text{VF 边界}, \text{向量宽度}, \text{展开因子})$。

联合空间 $\mathcal{D} = \mathcal{D}_1 \times \mathcal{D}_2 \times \mathcal{D}_3$（忽略层间约束时为笛卡尔积）。

> **关键结构**：层间存在**可行性约束**（不是所有组合都合法），所以 $\mathcal{S} \subsetneq \mathcal{D}$。这既让问题变难（约束耦合），也让问题有救（约束剪枝）。本课题的核心张力就在此处。

## 2 空间规模的推导

### 2.1 融合划分

- 若算子拓扑序固定、只允许在**相邻边**切分（即把序列切成若干段）：$2^{n-1}$ 种。
- 若允许任意划分（存在并行分支）：Bell 数 $B_n$。$B_{100}$ 约 $10^{115}$ 量级。

$n=100$ 时 $2^{99}\approx 6.3\times10^{29}$。**这是下界性质的量级**，实际可行解受依赖与容量约束会显著减少。

### 2.2 组内参数

每个融合组还要选择：

| 维度 | 典型取值数 | 说明 |
|---|---|---|
| tile 形状（M/N/K） | $10^2\sim10^3$ | 受对齐、片上容量约束 |
| core 划分 | $10^1$ | 多核切分方式 |
| buffer 深度/复用 | $10^1\sim10^2$ | double/triple buffer、复用方案 |
| 同步粒度 | $10^1$ | 组内屏障位置 |
| VF 边界 | $10^1\sim10^2$ | 向量化融合的切点 |

单组约 $10^6$ 组合；但组间**可分离**（同组参数互不影响，除容量共享），这是分层能奏效的结构性原因。

### 2.3 数值表（用于论文的"动机图"）

| $n$（融合步骤） | 划分方案（相邻切分） | 若每组 $10^3$ 参数、组数 $\approx n/5$ | 合计 |
|---|---|---|---|
| 10 | $5\times10^2$ | $10^{3\times2}=10^6$ | $10^{8.7}$ |
| 30 | $5\times10^{8}$ | $10^{18}$ | $10^{26.7}$ |
| 100 | $6.3\times10^{29}$ | $10^{60}$ | $10^{89.8}$ |

> 数字仅用于说明**增长阶**，不是精确计数；论文中应给出实测的可行解规模（任务 T-1.2）。

## 3 代价模型：为什么"平铺"必输

### 3.1 两个成本因子

- **单次评估的上下文长度** $L$：与程序表示规模成正比，$L_{\text{flat}} = \Theta(n\cdot p)$（$p$ 为每算子平均 token）。
- **评估次数** $N$：要覆盖解空间（或足够采样）。

总成本 $C \approx N \cdot L$。两个因子都随 $n$ 增长 → **二次以上的恶化**。

### 3.2 分层的代价上界（本文的"乘法变加法"命题）

**命题（代价上界，平凡但关键）**：若第 $k$ 层枚举 $|\mathcal{D}_k|$ 个候选、允许 $b_k$ 次回溯，则分层搜索的总评估次数

$$N_{\text{layered}} \;\le\; \sum_{k=1}^{K} b_k \cdot |\mathcal{D}_k|$$

而联合搜索在最坏情况下需要 $\Theta(|\mathcal{D}|) = \Theta(\prod_k |\mathcal{D}_k|)$ 次评估。

**推论**：当 $b_k = O(1)$ 且各层规模同量级 $|\mathcal{D}_k|=m$ 时，$N_{\text{layered}} = O(Km)$，而 $N_{\text{flat}} = O(m^K)$。**指数变线性**。

**但**：这个上界只在"层间约束可被局部吸收"时成立。若约束迫使频繁回溯，$b_k$ 可能指数增长，收益消失。**这正是 RQ2/KS1 要回答的问题**，也是本课题不敢直接宣称"一定更快"的原因。

### 3.3 上下文长度

$$L_k \ll L_{\text{flat}} \quad\text{因为}\quad L_k = \Theta(|\mathcal{V}_k| + |\Omega_k|)$$

分层后每次评估只装**该层**的变量与视图。这是 token 成本下降的**直接机制**，也是最容易测量、最不容易被质疑的收益。

### 3.4 为什么动态规划不适用

关键在代价是否可加。若融合代价**可加**，保序划分的最优解可用 $O(n^2)$ 动态规划精确求出（XLA/TVM 的融合策略正是此类），此时 $2^{99}$ 不构成困难。

本课题针对的是代价**不可加**的情形：

$$f(\pi) \neq \sum_{g\in\pi} f(g)$$

三个破坏最优子结构的原因：

| 原因 | 机制 | 后果 |
|---|---|---|
| **UB 容量共享** | 各组的片上占用竞争同一块 UB | 组的可行域依赖其他组的选择 |
| **CV 流水重叠** | 计算与搬运可在时间上重叠，组间时延相互影响 | 局部最优不蕴含全局最优 |
| **buffer 复用** | 生命周期交叠决定能否复用，代价对划分非局部 | 加性分解失效 |

**推论**：DP 的最优子结构假设被破坏，问题退化为一般的组合优化 + 非线性代价。这才是"必须搜索、且搜索必须分层"的理由。

**需要的实证**（T-1.6）：构造一个实例，DP 给出的"最优"划分在真实执行中比另一个划分慢 ≥2×。若造不出这个反例，说明代价近似可加，课题动机需大幅弱化。

> 诚实边界：不可加不等于 NP 难。本文不主张复杂性结论，只主张"在该结构下，枚举与 DP 都不可行，搜索是唯一出路"。

## 4 与 NP 难的关系

- 本问题**是**组合优化，规模大时不可精确求解；但并非所有实例都 NP 难（若代价可加，$O(n^2)$ DP 即可）。
- 本文不以 NP 难为论据，而以**代价不可分解**（§3.4）为论据：它更具体、可测。
- 本文不主张复杂性结论，只主张：**在预算受限的 Agent 场景下，分层精化把"不可完成的全局搜索"变成"可完成的序列局部搜索"，并给出可靠性与终止性的可证界**（不保证完备，不保证最优）。
- 诚实定位：这是一个**系统 + 算法工程**贡献，附带一个**搜索可靠性**的小结论（失败单调、终止性），不是复杂性理论突破。

| **T-1.1** | 选 3 个真实 MegaKernel 图，统计 $n$、分支数、可融合边数 | 图统计表 | $n \ge 50$ 的实例至少 1 个 |
| **T-1.2** | 在真实约束下枚举/采样可行解，估计 $|\mathcal{S}|$ | 规模估计 + 增长曲线 | $|\mathcal{S}| \ge 10^6$（否则动机需重写） |
| **T-1.3** | 测平铺式 Agent 单次评估的 token 与时间 | 成本基线 | 单次 ≥ 20k tokens（说明上下文确实是瓶颈） |
| **T-1.4** | 测"解质量 vs 评估次数"曲线（平铺 vs 随机采样） | 饱和曲线 | 存在明显饱和（说明"多试"不涨） |
| **T-1.5** | 统计层间约束的耦合强度（多少比例的下层选择会违反上层不变量） | 耦合率 | < 30% 则分层可行 |

> T-1.2 与 T-1.5 是**最可能推翻本课题**的两个测量。先做它们，比先写系统更划算。

## 6 反例与边界（自我攻击）

1. **小图反例**：$n=5$ 时平铺搜索完全够用，分层反而增加开销（层间切换成本）。→ 本文必须声明适用域 $n\gg 10$。
2. **强耦合反例**：若 VF 融合几乎总是改变 buffer 需求，则 Buffer 与 Register 层不可分离，三层退化为两层。→ 这不否定课题，但要求把层数当作**可调参数**而非教条（原文"A6 具体层按业务扩展"已预留）。
3. **编译器不配合**：若编译栈只能生成平庸 pipeline，Tile 层再聪明也到不了峰值。→ 需要 §R1 的"半自动 contract"作为兜底，并把"编译栈自动化质量"作为独立测量项，而不是隐藏假设。
