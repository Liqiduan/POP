# 红队意见：POP 开题（审稿视角）

**总判**：问题真实、时机对，但三支柱（组合爆炸、单向性、层间契约）均非可证伪命题；按现稿投 OSDI/ASPLOS，最可能被判"工程分层 + 借权威叙事"。

## 1 量化

**A1 "100 的组合种"无定义且量级错** → 致命 → 若指 C(100,2)=4950，低估约 26 个数量级；正确对象有三个：保序融合划分 2^99≈6.3×10²⁹（99 个"切/不切"），任意分组 Bell(100)≈4.8×10¹¹⁵，再乘 tiling 乘积（50 组×4 维×5 档≈2^460），合计约 2^560。修补：全文改用"决策位数/log₂ 空间"，逐项给公式与约束（保序、容量、对齐），删除"100 的组合种"。

**A2 "空间大 ⇒ AI 解不了"是非论证** → 致命 → 2^99 的保序分割若有可加代价，DP 是 O(n²) 精确最优（XLA/TVM 融合即如此）；NP 难是最坏情况，且 LLM 从不枚举——数字写错不必然使动机垮，但"爆炸=难解"这条推理必须换掉，否则动机确实垮。修补：改为"代价不可分解"——UB 容量耦合 + CV 流水重叠破坏最优子结构；并给一个 DP 最优、实测却差 2× 的反例。

**A3 上下文与成本无标度证据** → 重要 → "少上下文=少 token=更优"是断言。修补：固定模型与预算，画"决策变量数 vs pass@1/token/墙钟"曲线并报斜率。

## 2 单向性

**A4 ≐ 未定义等价物** → 致命 → 若指解集合则恒真（任何合法终态都可由某条路径到达），不构成定理；若指路径则假；若指最优性，不同路径落到不同局部最优，≐ 不保值。反例：C 层 VF 因寄存器压力失败、可行 B′ 不存在，只能回退改 A——这正是带回溯搜索。修补：改名"失败单调 + 冲突定向回跳"，证明 (a) 各层契约 sound（不把不可行判为可行）(b) 不可行性对精化单调 (c) 终止（秩函数 lex(layer,index) 下降）(d) 显式声明不保证完备与最优。

**A5 缺回跳深度证据** → 重要 → 若多数 C 层失败必须上抛 A，"逐层缩小空间"的收益即不成立。修补：instrument 失败层与回跳落点，给分布直方图；这是支撑主张最便宜的实验。

## 3 契约完备性

**A6 层间耦合是结构性的** → 致命 → A 决定 UB 驻留张量⇒决定 B 的 buffer 宽度；A 的 tiling 决定对齐与连续性⇒决定 C 的向量化是否合法（C 对 A 是偏函数）；C 的 VF 融合改变寄存器压力与指令 mix⇒改变 B 的最优双缓冲深度；B 的同步又改变 A 的代价。修补：契约从"每层谓词"升级为 assume–guarantee 关系（B 携带 regs≤R 的符号上界供 C 反证），或把耦合变量上提为粗层容量约束，并证非循环。

**A7 "不可判定"用词错误** → 重要 → 这是"局部目标未良定义"，不是可计算性。修补：改为"局部目标不闭合，需上层参数化"。

**A8 观测与评价混淆** → 重要 → Tile 层"不看内存/同步"，但融合方案优劣恰由它们决定，Tile 层凭什么排序？修补：区分"决策可见"与"代价可见"：变量分层，代价模型必须全局，或给可分解误差界并实测该界。

## 4 收益归因

**A9 现有设计无法归因** → 致命 → 收益可能来自分层、CANN 自动调度、LLM 本身、token 预算或 trace 观测；exp-plan 的 E2/E5 只切开"观测"与"分层"，且只比单一操作点。修补：报 success-vs-budget 曲线（token/墙钟/采样数），flat 与 layered 同轴比；加"同一分层空间内无 LLM 的随机搜索"基线，分离空间约束与 LLM。

**A10 人机成本未入账** → 重要 → "人可拖动 grouping、AI 可交互"意味着专家时间；不计介入次数，"降本"结论不成立。修补：定义人机预算（如 ≤2 次介入/算子），主表并列 AI 成本与人力工时，并报首可用解时间。

## 5 Novelty

**A11 与现有工作重合度高** → 致命 → (1)(2)≈TileLang/Triton（tile DSL+编译器管内存/同步）；逐层细化≈MLIR progressive lowering + Ansor 的 sketch→annotation；(4)≈trace 驱动调优。剩余新意仅"把 LLM 放进带契约的层次决策空间"，须由 A9 证明优于两者组合。修补：贡献收窄为一句可证伪命题，与三者同题对比。

**A12 谱系借用是隐喻** → 重要 → Nested BSP 原文讲百万处理器、peer 超步、Unified Bus、τ 标度律，属体系结构，不含 contract/refinement/观测形式化；其"层"是并行层级而非抽象层级；检索未证实"Nested VISA"。修补：引原文可引定理并给编号，否则删谱系段，改引 MLIR/Ansor/Halide 的 schedule 层次。核实：Nested BSP 摘要级已核实（arxiv.org/abs/2609.16787）；VISA 未核实。

## 6 可行性

**A13 范围过大 + 950 不确定** → 致命 → 三层 IR+agent+cost model+trace/replay UI+契约理论≈5–8 人年；950 可得性与 PyAsc 成熟度未定，评测不可复现。修补：砍到 Tile→Buffer 两层 + 一个融合家族，MegaKernel 只做一个 case；补 910B/模拟器回落与 CANN 锁定。

**A14 "编译栈自动完成"是双刃** → 重要 → 若成立，Tile 层≈现有 Ascend C，贡献被后端吞掉；若不成立，进度表崩塌。修补：先做 spike，用现有栈生成 3 个融合组，量"自动 vs 手写"差距——这同时是契约 soundness 的下界。

**A15 公平性与负例** → 重要 → 融合更多不一定更快（UB 溢出、指令缓存、占用率）。修补：预注册、固定频点、≥30 次、报中位与 CI，纳入"融合变慢"负例。

## 如果只修三件事

1. **量化**：改"决策位数"，给 2^99/Bell/乘积三式与不可分解代价的反例，删"100 的组合种"。
2. **单向性**：改为"失败单调 + 冲突回跳"，补 soundness/终止证明与回跳深度分布。
3. **归因**：等预算 best-of-k 曲线 + 无 LLM 随机搜索基线；这是判决实验。
